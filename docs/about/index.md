# 關於這個 Archive

Research Observatory 保存、整理與呈現長篇研究內容，其中包括由 ChatGPT deep research、Gemini Deep Research、Grok DeepSearch、Claude Research，以及其他搜尋／推理工作流產出的報告。

「Deep Research」不是跨公司的正式標準。各家產品名稱、模型、資料來源、引用方式與可用範圍都會變動；保存報告也不代表替內容或供應商背書。
