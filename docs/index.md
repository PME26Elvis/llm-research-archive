# Notes

這是一個長文研究筆記庫，主要用 MkDocs Material 管理分類、標籤、時間軸與文章索引。

## 快速入口

- [文章字數總表](word-counts.md)：查看每篇文章的字數、預估閱讀時間，並依字數由多至少排序。
- [Tags](tags.md)：用跨分類關鍵字找文章。
- [Timeline](timeline/index.md)：用時間軸與歸檔瀏覽文章。
- [LLM](llm/index.md)、[Carbon](carbon/index.md)、[CS 文章](cs/cs-super-tree-report/index.md)：依主題分類瀏覽。

## 使用提示

- 每篇有日期 metadata 的文章頁會自動顯示字數統計與閱讀時間。
- 文章上架或修改後，MkDocs build 會自動重新產生字數總表。
