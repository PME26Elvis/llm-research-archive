## 使用提示

- 每篇有日期 metadata 的文章頁會自動顯示字數統計與閱讀時間。
- 文章上架或修改後，MkDocs build 會自動重新產生字數總表。
- 可用右上角切換淺色 / 深色模式；搜尋框可直接查標籤、標題或全文內容。
