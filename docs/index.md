## 新增閱讀體驗

!!! tip "更像一個互動式研究庫"
    - 頂部導覽改為 tabs / sections，長文分類更清楚。
    - 搜尋支援建議、關鍵字標亮與分享查詢連結。
    - 頁面載入有 instant navigation 與進度提示，返回頂端按鈕也已啟用。
    - 圖片自動支援 lightbox，未來有圖表或截圖時可直接放大檢視。

## 使用提示

- 每篇有日期 metadata 的文章頁會自動顯示字數統計與閱讀時間。
- 文章上架或修改後，MkDocs build 會自動重新產生字數總表。
- 可用右上角切換淺色 / 深色模式；搜尋框可直接查標籤、標題或全文內容。
